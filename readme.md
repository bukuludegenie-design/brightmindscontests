# Bright Minds Contest (BMC) website

A responsive, static website built with HTML, CSS and JavaScript. No Python backend is required for this version.

## Files
- `index.html` — page content and structure
- `style.css` — responsive visual design
- `script.js` — navigation, WhatsApp button and interactive demo analytics
- `logo.png` — supplied BMC logo

## Before publishing
1. Open `script.js`.
2. Replace `211XXXXXXXXX` in `BMC_WHATSAPP_NUMBER` with BMC's official WhatsApp number. Use digits only, including the country code.
3. Confirm leadership names, program details and other organization information.
4. Upload all four files to your web host, keeping them in the same folder.

## Analytics note
The dashboard uses illustrative focus-distribution values and starts with zero activity records. The activity form updates charts in the current browser session only; it does not save records to a server or share data between devices. For persistent, multi-user analytics, connect a backend/database and restrict access appropriately.

## Deployment
You can publish this static site with Netlify, GitHub Pages, or another static website host. Upload the contents of this folder or deploy the ZIP through your host's supported workflow.
